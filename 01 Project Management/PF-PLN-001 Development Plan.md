# Development Plan

## Phase 0 — Project control

- Establish repository, vault, document control, requirements, decisions, risks, and action tracking.
- Consolidate prior discussion into controlled drafts.

## Phase 1 — Requirements and architecture

- Confirm player, performance, aesthetic, manufacturing, ethical, and cost requirements.
- Freeze vocabulary and compare architecture alternatives.
- Identify claims requiring simulation or physical tests.

## Phase 2 — Parametric CAD and analysis

- Build center spine, neck interface, wing envelope, attachment interfaces, cavities, and hardware references.
- Run mass, balance, tolerance, structural, and modal studies.
- Compare simple control geometry against proposed internal structures.

## Phase 3 — Test articles

- Print material coupons and joint samples.
- Test fit, creep, humidity/temperature response, adhesive compatibility, damping, and failure modes.

## Phase 4 — Alpha prototype

- Build the simplest credible full instrument.
- Prioritize tuning, setup, structural behavior, ergonomics, assembly, and baseline measurements.

## Phase 5 — Beta prototype and external review

- Incorporate Alpha lessons.
- Conduct structured player evaluations and controlled comparisons.
- Review manufacturability, ethics, cost, and IP before outreach.

## Gate rule

Each phase requires updated requirements, decisions, risks, evidence, open questions, and a documented go/no-go recommendation.
